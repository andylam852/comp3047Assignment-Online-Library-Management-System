# Online Library Management System

A full-stack web application for managing books, users, and library operations. This project was developed as part of a Hong Kong Baptist university coursework assignment and demonstrates skills in web application development, database management, authentication, and CRUD operations.

## Project Overview

This system allows library staff and users to:
- Add, edit, and delete books
- Search for books by title, author, or category
- View book details
- Manage user accounts
- Authenticate users with role-based access
- Support common library operations in a simple web interface

## Tech Stack

- Node.js
- Express.js
- MongoDB
- EJS
- JavaScript
- HTML/CSS

## Features

- User authentication and authorization
- Role-based access control
- Book catalog management
- Search and filtering
- Responsive web interface
- Data persistence using MongoDB
